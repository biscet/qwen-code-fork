# Оптический размер и бесплатные модели без регистрации

В Lucide Bot корпус занимает 16 × 12 единиц viewBox, а Server — 20 × 20. Одинаковый SVG box не обеспечивает одинаковый визуальный размер. Увеличить только рисунок Bot на 25%, сохранив занимаемые 16 px и толщину линии (strokeWidth 1.6 до масштабирования). Это применяется к списку, редактору и категории моделей.

Запрос пользователя теперь касается любых подходящих бесплатных моделей без регистрации. LLM7 документирует анонимный доступ с публичным значением `unused` вместо персонального ключа. Codestral (`codestral-latest`, 32 000 токенов контекста) и GPT-OSS (`gpt-oss`, 131 072 токена) успешно прошли реальные запросы, SSE и function/tool round trip 5 сентября 2026. Текущий ответ GPT-OSS идентифицирует backend как gpt-oss-20b; имя подключения сохраняет публичное название GPT-OSS, поскольку провайдер управляет алиасом.

Через существующий model-settings API добавить оба подключения в пользовательскую область и текущий tetris, где есть собственный список моделей. Сохранить существующие подключения, ключи, основную local-coder и modelFallbacks. Автоматическое переключение не включать. Блок бесплатных API показывает проверенный сервис и его общие анонимные лимиты, а не прежнее утверждение об отсутствии открытых API.

Источники: [анонимный доступ](https://docs.llm7.io/quickstart), [каталог](https://docs.llm7.io/guides/models), [лимиты](https://docs.llm7.io/limits). Pollinations вернул 401/402; MiniMax в LLM7 завершился таймаутом; AdFreeLLM выдал анонимный ключ, но генерация вернула 403. Эти подключения не добавлять. AI Horde документирует анонимный доступ, но не выбран вместо двух проверенных моделей с инструментами.

Проверка: `.qwen/issues/homecode-model-optical-icon.md`, `.qwen/e2e-tests/anonymous-model-api-probes.jsonl`, `.qwen/e2e-tests/anonymous-model-tools-probes.jsonl`; build/typecheck/bundle, целевые тесты, оптическое сравнение в браузере и реальном HomeCode, а также изолированный запрос через HomeCode CLI.
