# Точечные исправления настроек моделей

По замечаниям пользователя от 5 сентября: сохранить оформление HomeCode и исправить шесть проблем интерфейса.

- «Настроить» и «Удалить» используют существующий Button с outline и одинаковыми отступами.
- В навигационной панели убрать стандартный логотип. Кнопка сворачивания на macOS следует за правым краем панели при изменении ширины; в свёрнутом состоянии раскрытие остаётся доступным рядом с оконными кнопками. Пользовательский branding.render сохраняется.
- Иконки категорий и заголовков имеют фиксированные 16 × 16 px и не сжимаются.
- При наличии редактора подключений общие настройки из категории Model показываются отдельным пунктом «Параметры чата». Ключи, значения и выбор области сохраняются; в редакторе остаются только поля конкретной модели. Legacy-интеграция без modelSettings сохраняет прежнюю группировку.
- Русские значения состояний: «Включено» и «Выключено».
- Формы добавления и редактирования занимают доступную внутреннюю ширину блока. Сохраняются текущие поля и адаптивная сетка.
- Действие выбора текущей модели выглядит как обычная outline-кнопка. Характеристики подключения показаны компактным списком «метка — значение» с тонкими разделителями.
- Из fallback-блока убрана датированная проверочная проза. Опубликованные лимиты LLM7 показаны тремя спокойными линейными шкалами в существующих цветах HomeCode; шкалы обозначают верхнюю границу, а не измеренный расход общей анонимной квоты.

Изменения ограничены Web Shell. Подключения, ключи, backend и core не меняются. План проверки: `.qwen/e2e-tests/homecode-model-settings-polish.md`.
