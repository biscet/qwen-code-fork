# Оформление моделей и бесплатный fallback

## Задача

Список моделей на странице настроек визуально оторван от «Параметров чата»: другой фон, отступы и отдельные ссылки подключения провайдеров. Пользователь просит одинаковое спокойное оформление, отдельный блок «Fallback бесплатные модели» и только обычное добавление моделей.

## Решение

Использовать те же Card, CardHeader, CardTitle и CardContent, что и «Параметры чата». Сохранить палитру, шрифт, тонкую обводку и компактные строки приложения. Первый блок содержит сохранённые модели и кнопку добавления; второй — бесплатный fallback; ниже остаются параметры чата. Редактор открывается внутри оформленного блока моделей. Новые CSS-примитивы, палитра, анимация и декоративные карточки не нужны.

Убрать onAddProvider и callback добавления из legacy modelManagement в полноэкранных настройках App: оба пути открывают мастер сторонней авторизации. Старый список сохраняет выбор и удаление моделей, а optional onAddModel скрывает недоступное добавление. Команда /auth в Web Shell открывает категорию «Модели»; неиспользуемый AuthMessage dialog и его состояние убираются. Обычный ModelEditor продолжает сохранять точное OpenAI-совместимое подключение. Существующие подключения, ключи, выбранная модель, CLI-авторизация и runtime-маршруты не меняются.

Каталог fallback предлагает только подтверждённые бесплатные Qwen 27B, которые соответствуют условиям пользователя. Ни открытие страницы, ни сохранение модели не включает автоматическое переключение. Настроенный modelFallbacks остаётся явным выбором пользователя. Если подходящих публичных API нет, показать это в отдельном блоке без нерабочих кнопок подключения. Уточнение про допустимость бесплатного API с ключом было задано во время работы. При отсутствии ответа принят строгий вариант: без регистрации и ключа. На 5 сентября 2026 работающий подходящий API не подтверждён, поэтому блок показывает датированный статус и ссылку на официальное сообщение о закрытии публичного HF endpoint.

## Проверка доступности на 5 сентября 2026

- Публичный [Hugging Face endpoint](https://victor-qwen3-8-27b-free-endpoint.static.hf.space/index.html) без ключа официально закрыт (Notice: endpoint retired).
- [Immers](https://en.immers.cloud/ai/Qwen/qwen3.8-27b/) требует регистрацию, верификацию и API-токен.
- [OrcaRouter](https://www.orcarouter.ai/de/models/qwen/qwen3.8-27b-free) требует свой API-ключ.
- [ModelScope](https://modelscope.cn/docs/model-service/API-Inference/limits) требует аккаунт и ключ по существующему описанию; не считать это доступом без регистрации.
