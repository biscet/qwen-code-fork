# Выбор моделей в настройках HomeCode

## Задача

В видимых настройках «Модель-советник» и «Модель поиска» сейчас используются свободные текстовые поля. Из-за этого легко ввести ID, которого нет в активной рабочей области. Для модели-советника пустое значение означает основную модель; в текущем HomeCode это локальная Qwen3.8-27B (`local-coder`).

## Решение

Использовать существующий Select Web Shell и фактический список моделей выбранной рабочей области. Текущую основную модель показывать первой. Для пустой модели-советника отображать её как выбранную по умолчанию, сохраняя существующую семантику наследования основной модели. Для модели поиска не подставлять локальную модель автоматически: этот маршрут требует совместимую поисковую модель, поэтому без сохранённого значения остаётся явное «Выбрать».

Существующие значения, которых временно нет в списке провайдеров, остаются отдельным пунктом и не теряются. Остальные строковые настройки и специализированные диалоги выбора моделей не меняются.

## Проверка

- Оба прежних текстовых поля отображаются как селекты в родной стилистике HomeCode.
- Пустая модель-советник показывает текущую локальную Qwen3.8-27B.
- Сохранённая модель поиска и выбранная область настроек сохраняются.
- Неизвестное сохранённое значение остаётся видимым.
