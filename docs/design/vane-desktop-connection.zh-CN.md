# Vane 桌面连接

[English](vane-desktop-connection.md) | [简体中文](vane-desktop-connection.zh-CN.md)

## 问题

全新安装的 HomeCode 在没有家庭服务器 API 密钥时无法加载 Vane 模型，而 Vane
设置没有密钥输入入口。默认模型必须是 Qwen3.8-27B，连接设置完成前也应显示。

## 设计

即使远程模型目录不可用，Vane 设置仍提供 API 密钥密码输入框和保存按钮。
仅显示是否配置密钥，绝不向浏览器返回已保存的密钥。保存后清空输入框，重新加载
模型，并通知 Chat 刷新目录。保存失败时保留输入值，以便重试。

使用进程全局的 HomeChat 连接端点，并复用现有守护进程身份验证与严格写入中间件。
将用户明确输入的密钥保存到私有的用户 HomeChat 存储，并用于固定的桌面 HomeChat
网关。在用户保存覆盖值之前，继续使用现有密钥回退来源。此变更不修改 Harness
身份验证或 Codex 凭据。

优先选择 Vane 实际公布的 Qwen27B 模型，同时识别已有的旧 Windows 模型标识符。
当新桌面安装无法获取目录时，显示内置 Qwen27B 预设。保留有效的已保存模型选择。
开始研究前，服务器仍须依据实时提供商目录验证模型；显示预设不表示远程服务可达。

## 范围和验证

修改 HomeChat 路由与存储、Vane 设置、API 辅助函数、翻译和针对性测试。DMG 不包含
服务器模型部署或凭据。验证全新安装、密钥缺失或无效、保存与重新加载、私有持久化、
身份验证转发以及保留已有选项。在 `.qwen/e2e-tests/homecode-2.1.12/` 中分别记录
原生或浏览器验证证据与模拟路由或 DOM 测试结果。没有待决设计问题。
