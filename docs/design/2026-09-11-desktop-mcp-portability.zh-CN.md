# 桌面 MCP 可移植性

[English](2026-09-11-desktop-mcp-portability.md) | [简体中文](2026-09-11-desktop-mcp-portability.zh-CN.md)

## 问题

新的受信任项目会获得 HomeCode 的 MCP 默认配置，但复制的项目即使已经包含
这些配置，也没有新 Mac 本地的外部安装记录，因此服务器仍然等待批准。
如果密钥来自 settings.env，研究服务的批准也可能在首次启动时立即失效：
批准过程和工作区子进程必须使用完全相同的运行环境解析结果。从另一台 Mac
复制的标准 skill Markdown 也可能保留指向原机器脚本的绝对路径。

标准本地 Qwen 路由要求启用思考。Auto 权限分类器默认请求关闭思考；如果模型
没有声明已有的强制思考能力标记，就会收到 HTTP 400 并回退为人工批准。
启用强制思考后，分类器的 256 令牌输出上限又可能截断结构化判断，导致 HTTP 422。
快速阶段的 10 秒超时也会中止有效的强制思考请求：重放真实 Node REPL 和 Serena
操作时，分类分别需要 21.3 秒和 14.5 秒。

## 行为

仅在受信任的桌面项目中识别与应用自带配置完全一致的 MCP 定义，也覆盖已有
空安装记录的项目。接管当前自带的本地定义，并将与自带远程默认值完全一致的
定义迁移为本地 Node REPL、Serena、Playwright 和 Chrome DevTools。
Home AI Research 继续使用自带的、经过认证的 HTTPS 地址。所有权记录仅写入
本地用户配置目录，不导入另一台机器的批准文件。

保留自定义定义、.mcp.json 冲突、明确的排除和拒绝，以及缺失或已删除的服务器。
接管不会恢复已删除的条目，也不会启用已禁用的服务器。这仅针对已知的应用
能力扩展原先仅由安装程序拥有配置的规则；任意项目命令仍然需要批准。

使用与工作区子进程相同的环境解析过程计算批准指纹。批准前验证本地定义仍然
解析为当前应用内置的 Node 和启动器，并带有预期的服务器参数。项目环境变量
覆盖不能把标准声明变成已批准的自定义可执行文件。验证研究服务的固定地址和
凭据模板边界。

仅当已安装 skill 或 agent Markdown 的完整内容与自带模板或旧版安装程序
对该模板的渲染完全一致时，才更新脚本引用，使其指向当前用户配置或项目路径。
保留自定义 Markdown、脚本、缺失文件和符号链接，不覆盖它们。

为自带 local-coder 配置声明 `generationConfig.thinkingMandatory: true`。
仅在精确匹配自带局域网或本地回环地址的配置中补充缺失的能力标记，也包括
已经使用原生 Qwen 推理格式的配置。保留明确的能力和推理覆盖、自定义路由和
格式、已删除的模型以及模型配置中的现有令牌预算。

在第一阶段分类前解析实际的辅助查询模型，包括明确指定的快速模型路由。
仅为必须思考的生成器提供 2048 个输出令牌和默认 60 秒的第一阶段超时；
其他生成器继续使用 256 个令牌和 10 秒。较长超时为实测 21.3 秒的分类提供余量，
并保留原有的两次尝试上限。保留有效的显式超时设置，模型解析所耗时间也计入
截止时间。保留第二阶段行为和失败策略，不统一授予工具调用权限。

## 范围

仅涉及桌面默认配置安装、标准模型能力、skill 引用、受信任工作区初始化以及依据模型能力设置的分类器输出和时间预算。主工作区、恢复的工作区以及
动态添加的受信任运行时共用该初始化过程。HomeChat 和不受信任的工作区保留
现有默认配置初始化边界。安装程序保留自定义模型路由和显式覆盖；对于任意
路由，分类器都使用实际解析模型的能力。工具调用批准模式保持不变。无需新增
守护进程路由或界面设置。

## 验证

使用隔离的用户配置，以及新项目、已有项目、复制项目和不受信任的项目。
验证重复启动、已有空安装记录、应用路径变更、settings.env 密钥、自定义覆盖、
排除或拒绝或已删除的服务器，以及环境变量替换尝试。将打包运行时移动至带空格
的路径后，执行真实的本地 MCP 调用。验证工作区内的符号、REPL 工作目录和
浏览器对该 Mac 的 localhost 的访问。运行针对性测试、构建、类型检查、
签名和校验和检查，并对本任务差异进行两次检查。
在能力修复前验证分类器的 HTTP 400，修复后验证真实的 Auto 工具批准结果。
仅未出现 HTTP 400 并不足以通过验证；超时或令牌预算失败仍必须报告。
覆盖必须思考和不必思考的快速模型覆盖，确保不会根据主模型能力设置另一个
分类器模型的预算。测试显式超时以及模型解析所耗时间。确认真实 MCP 调用在
Auto 模式下无需人工批准即可完成。

## 验收与限制

在满足前提条件时，标准 MCP 应在受信任的新项目和复制项目中自动连接，无需
逐服务器设置。研究服务需要用户有效的家庭服务器密钥、受信任的局域网证书和
网络连通性。必须通过真实模型与工具的往返调用验证模型使用情况；连接成功
不代表模型会在每项任务中选择 MCP。分别报告迁移后的隔离配置测试与第二台
实体 Mac 上的测试。可移植的 Apple Silicon 安装包要求 macOS 15 或更新版本，
并使用 ad-hoc 签名。
