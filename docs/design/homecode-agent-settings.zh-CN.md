# HomeCode 代理设置与 Qwen 0.23.2

[English](./homecode-agent-settings.md)

HomeCode 2.1.8 隐藏了 Qwen 已有的输出语言和并行代理设置，内置引擎版本为 0.22.3。本次发布公开这两个原生设置，将桌面版默认回复语言设为俄语，更新到官方 0.23.2 源码标签，并构建适用于 macOS Apple Silicon 的 HomeCode 2.1.9。

设置页继续使用现有的作用域设置 API 和共享控件。`agents.maxParallelAgents` 仅接受正整数，限制每个 Qwen 会话中同时运行的后台代理；超额代理进入现有队列。设置在运行时重启后生效。用户未设置时保留原有的十个代理默认值。不重写调度器，不新增按模型设置的控件。

`general.outputLanguage` 通过语言选择器公开。保存设置时必须在所选作用域写入原生输出语言指令，以确保后续会话实际使用该语言。主代理和子代理已继承此指令。桌面默认配置将语言初始化为俄语，并迁移旧版桌面安装，同时保留明确设置的语言。Codex Harness 也使用相同的有效语言指令，其已有的禁用子代理策略保持不变。

路由保持原有的所有权：`/workspace/settings` 属于旧版主工作区，可写入用户设置或主工作区设置；`/workspaces/:workspace/settings` 必须解析受信任的选定运行时，并且只能写入该工作区。语言指令路径必须遵守此作用域。选定运行时出现任何故障时都不能回退到主工作区。

合并上游源码时保留 HomeCode 品牌、自定义界面、模型设置、HomeChat 和 Codex 集成。冲突解决仅限于适配新引擎。桌面清单、锁文件元数据、Rust 包版本和客户端显示版本同步更新。本任务不包含提交、推送、服务部署或修改用户的实际配置。

验证涵盖设置 API 可见性、按作用域持久化、非法限制值、界面控件、现有队列和并发限制、原生俄语指令、桌面迁移、重点合并回归、构建和类型检查、运行时与挂载 DMG 的启动、macOS 签名资源完整性及磁盘映像完整性。第二台 Mac 上的实际验收由用户完成。
